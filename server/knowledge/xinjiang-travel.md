# 新疆旅游指南

新疆是中国面积最大的省级行政区，南北疆风光迥异：北疆以草原、湖泊、森林为主，南疆以沙漠、绿洲、人文风情见长。

## 北疆重点
- **喀纳斯**：秋色绝佳（9月下旬-10月上旬），湖水随光线变色，禾木村晨雾出名。
- **伊犁**：那拉提、喀拉峻草原，5-6月花海；赛里木湖"大西洋最后一滴眼泪"。
- **独库公路**：贯通天山，每年仅6-10月开放，一日看四季，但限7座以下车辆。

## 南疆重点
- **吐鲁番**：火焰山、葡萄沟、坎儿井，夏季极热（40℃+）。
- **喀什**：老城、艾提尕尔清真寺，南疆人文核心，价格亲民。
- **塔克拉玛干**：沙漠公路，需充足补给与车辆准备。

## 注意事项
- 地域辽阔，城市间动辄数百公里，车程长，建议飞机+当地包车组合。
- 昼夜温差极大，哪怕夏季也需备厚外套。
- 部分边境地区（如白哈巴、塔县）需提前办理边防证。
- 安检严格，随身带身份证；尊重维吾尔等民族习俗与饮食禁忌（清真）。
- 最佳季节：北疆6-10月，南疆4-10月；冬季部分景区封闭。
